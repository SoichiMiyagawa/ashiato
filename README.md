# Ashiato — 足あとマップ

行った場所・通った場所の影が晴れていく地図アプリです。スマホでもPCでも同じWebアプリ（PWA）として動きます。

- 地図全体が半透明の黒い影に覆われていて、記録した場所だけ影が晴れます
- 世界中どこでも使えます（地図は OpenStreetMap）
- スマホ：位置情報を記録しながら地図を表示
- PC：記録済みの場所を見る（記録ボタンもありますが、使わなくても大丈夫です）
- 端末間の同期は、自分の GitHub の**非公開 Gist** を使います（サーバー不要）

## 使い方

### 1. スマホにインストール
公開URLをスマホのブラウザで開いて、ホーム画面に追加します。

- **iPhone**：Safari → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome → メニュー → 「アプリをインストール」

右下の ● ボタンで記録の開始/停止、◎ で現在地、⚙ で設定を開きます。

> **注意**：ブラウザの制約で、位置情報を記録できるのは**アプリを画面に表示している間だけ**です。
> 設定の「記録中は画面をつけたままにする」をオンにすると、記録中は画面が消えなくなります。
> バックグラウンドでも記録したい場合は、GPXロガーアプリ（Android の「GPSLogger」など）で記録して、
> その `.gpx` ファイルを設定 →「インポート」で取り込めます。

### 2. 同期の設定（スマホとPCでデータを共有する場合）
1. GitHub で [Fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) を作ります
   - Repository access：`Public repositories` のままでOK
   - Account permissions → **Gists**：`Read and write`
2. スマホのアプリで ⚙ → 「GitHubトークン」に貼り付け →「今すぐ同期」
   - 初回は Gist が自動で作られ、「Gist ID」欄に ID が入ります
3. PC でアプリを開き、⚙ → 同じトークン（または同じ権限で作った別のトークン）と、その **Gist ID** を入れて「今すぐ同期」

「自動で同期する」がオンなら、アプリを開いたとき・閉じたとき・10分ごとに同期します。
同期は両方のデータを足し合わせる方式なので、どちらかの記録が消えることはありません。

トークンはその端末のブラウザ内にだけ保存されます。

### データについて
- 位置は約11mのマス目に丸めて保存しています（時刻などは保存しません）
- 「エクスポート」で JSON として書き出し、「インポート」で読み込めます
- 「この端末のデータを消去」は端末内のデータだけ消します。Gist 上のデータは残るので、同期すると戻ります

## ローカルで動かす

```
python -m http.server 8765
```

http://localhost:8765 を開きます。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 地図・影の描画・記録・同期のすべて |
| `style.css` | 見た目 |
| `sw.js` | オフライン起動用のサービスワーカー |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
